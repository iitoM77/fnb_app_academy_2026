# Unit 2 Challenge – Password Hint Tool

## Overview
Create a Python script called `password_hint_tool.py` that helps users remember their password by showing a secure hint.  
The program demonstrates string cleaning, indexing, and formatted output.

---

## Requirements
1. Ask the user to input their secret password using `input()`.
2. Use `.strip()` to remove any accidental spaces at the start or end.
3. Extract the very first letter and the very last letter of the password using string indexing.
4. Print a hint using an f-string that forces the letters into uppercase so they stand out.  
   Format: `Your password hint: It starts with [FIRST] and ends with [LAST]`.

---

## Outcome
By completing this task, you will:
- Understand how to clean user input with `.strip()`.
- Access specific characters in a string using indexing.
- Apply f-strings for clear, formatted output.
- Build confidence in combining string methods and indexing to create useful tools.
