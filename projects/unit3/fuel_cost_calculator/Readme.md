# Unit 3 Challenge – Fuel Cost Calculator

## Overview
Create a Python script called `fuel_cost_calculator.py` that calculates the cost of a trip based on distance and petrol price.  
The program demonstrates type casting, arithmetic operations, and formatted output.

---

## Requirements
1. Ask the user how many kilometers they want to drive.
2. Ask the user for the current petrol price per liter (decimal values allowed).
3. Assume the car uses exactly 1 liter of fuel for every 10 kilometers driven.  
   Formula: `liters_needed = kilometers / 10`
4. Calculate the total cost: `liters_needed * petrol_price`
5. Use type casting to ensure numeric input works correctly.
6. Use `round()` to format the final cost to 2 decimal places.

---

## Outcome
By completing this task, you will:
- Understand how to collect and process numeric input safely.
- Apply arithmetic formulas to solve real-world problems.
- Use type casting to handle user input correctly.
- Format numeric results with `round()` for readability.
- Build confidence in combining input, calculation, and output in a single program.
