# Unit 1 Challenge – Concert Ticket Booker

## Overview
Create a Python script called `concert_ticket_booker.py` that acts as a digital ticket counter.  
The program collects user details and confirms a booking with a personalized message.  

This project demonstrates user input handling and f-string output formatting.

---

## Requirements
- Ask the user for their **name** using `input()`.
- Ask the user for the **band/artist name** they want to see using `input()`.
- Print a personalized confirmation message using an f-string:
  - Format: `Hey [Name]! Your tickets to see [Artist] are booked successfully!`

---

## Outcome
By completing this task, you will:
- Understand how to accept user input in Python.
- Store information in variables.
- Use f-strings to generate personalized, formatted output.

This project builds confidence in handling user input and formatting text, preparing you for more complex interactive programs later in the course.
