# Practical task 1 – Student Info Formatter

## Overview
Create a Python script called `student_info.py` that collects personal information from the user and displays it in a formatted profile card.  
This project demonstrates correct use of Python’s four data types, string manipulation, arithmetic, and f-string output formatting.

---

## 🛠️ Requirements
- Use `input()` to collect:
  - First name (string)
  - Surname (string)
  - Age (integer)
  - Favourite number (float)

- Display a formatted greeting using an f-string: `Welcome, [Full Name]!`

- Show the name in:
  - UPPERCASE using `.upper()`
  - Title Case using `.title()`

- Calculate and display the age in months (`age × 12`)

- Round the favourite number to 2 decimal places using `round()`

- Print the data type of each collected value using `type()`

---

## Outcome
By completing this task, you will:
- Be competent in creating and running a basic Python script.
- Understand how to accept user input and store information in variables.
- Apply string methods to manipulate text.
- Perform simple calculations with integers and floats.
- Use f-strings for formatted output.
- Confirm and display data types in Python.

This project represents your first step into programming and builds the foundational skills that will be expanded throughout the remainder of the course.
