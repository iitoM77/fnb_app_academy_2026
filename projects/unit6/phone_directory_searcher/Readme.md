# Unit 6 Challenge – Phone Directory Searcher

## Overview
Create a Python script called `phone_directory_search.py` that simulates a mini data directory using a combination of a list and a dictionary.  
The program demonstrates dictionary lookups, conditional logic, and formatted output.

---

## Requirements
1. Create a dictionary called `contacts` where:
   - Keys are friend names.
   - Values are their phone numbers (stored as strings to preserve leading zeros).
   - Fill the dictionary with at least 3 people.
2. Ask the user to input the name of the friend they want to look up.
3. Use a conditional check to see if the name matches a key in the dictionary.
   - If it exists, print: `Found! [Name]’s number is [Number]`.
   - Otherwise, print: `Contact not found.`

---

## Outcome
By completing this task, you will:
- Understand how to store and access data using dictionaries.
- Apply conditional logic to check for key existence.
- Safely handle user input for lookups.
- Use f-strings to display clear, formatted results.
- Build confidence in combining input, dictionaries, and conditionals in a single program.
