# FNB App Academy 2026– Python Projects

This repository documents my journey through the **FNB App Academy Programme**, focusing on Python fundamentals, data structures, and applied projects.  
It serves as both a learning log and a portfolio of completed work.

## Structure
- `projects/` → Contains individual Python projects from the programme and their respective Readme files for instructions for the tasks.
- `docs/` → Notes and concept explanations.


## Goals
- Build a strong foundation in Python programming.
- Apply concepts to practical projects.
- Document progress for future reference and sharing.

## Programme Coverage
- Python basics: variables, input/output, string methods
- Control flow: loops, conditions, dictionaries
- Data analysis and visualization
- Project-based learning
